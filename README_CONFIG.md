# WebSocket 配置页面使用说明

## 功能概述

这个配置页面允许您动态配置Chrome扩展的WebSocket连接地址，无需修改代码即可更改后端服务器地址。

## 访问配置页面

### 方法1：通过扩展选项页面
1. 在Chrome浏览器中打开 `chrome://extensions/`
2. 找到 "Host助手" 扩展
3. 点击 "详情" 按钮
4. 点击 "扩展程序选项" 链接

### 方法2：直接访问
在浏览器地址栏输入：`chrome-extension://[扩展ID]/config/config.html`

## 配置功能

### 1. WebSocket URL 配置
- **输入格式**：`ws://localhost:8000/ws/1/client` 或 `wss://your-server.com/ws/1/client`
- **支持协议**：ws:// (非加密) 和 wss:// (加密)
- **自动验证**：实时验证URL格式的正确性

### 2. 连接测试
- **测试按钮**：点击 "测试连接" 验证WebSocket服务器是否可达
- **超时设置**：测试连接有5秒超时限制
- **状态反馈**：实时显示连接测试结果

### 3. 状态监控
- **连接状态**：显示当前WebSocket连接状态
  - 🟢 已连接：WebSocket连接正常
  - 🔴 未连接：WebSocket连接断开
  - 🟡 连接中：正在建立连接

### 4. 配置持久化
- **自动保存**：配置会自动保存到Chrome本地存储
- **自动加载**：页面加载时自动恢复上次保存的配置
- **实时更新**：保存配置后立即应用到background script

## 使用步骤

1. **打开配置页面**
   - 通过扩展选项页面访问

2. **输入WebSocket URL**
   - 在输入框中输入您的WebSocket服务器地址
   - 格式：`ws://localhost:8000/ws/1/client`

3. **测试连接**
   - 点击 "测试连接" 按钮验证服务器可达性
   - 确认连接成功后继续

4. **保存配置**
   - 点击 "保存配置" 按钮
   - 配置将立即生效并重新连接WebSocket

## 支持的URL格式

```
ws://localhost:8000/ws/1/client          # 本地开发
wss://your-server.com/ws/1/client       # 生产环境
ws://192.168.1.100:8000/ws/1/client     # 局域网
```

## 错误处理

### 常见错误及解决方案

1. **URL格式错误**
   - 确保URL以 `ws://` 或 `wss://` 开头
   - 检查URL语法是否正确

2. **连接超时**
   - 检查服务器是否正在运行
   - 确认端口号是否正确
   - 检查防火墙设置

3. **连接被拒绝**
   - 确认WebSocket服务器已启动
   - 检查服务器地址和端口
   - 验证网络连接

## 技术特性

- **实时验证**：输入时实时验证URL格式
- **状态持久化**：配置自动保存和恢复
- **错误处理**：完善的错误提示和处理机制
